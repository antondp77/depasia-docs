## IMPORTANTE

Todavía NO existe el template visual definitivo del Presupuesto.

Por lo tanto, NO inventes el diseño final del PDF.

En esta primera etapa quiero preparar la base del proyecto para que el template pueda incorporarse posteriormente sin rehacer la arquitectura.

La prioridad es:

**Presupuesto → Preview → PDF**

Pero el primer paso debe ser preparar correctamente la aplicación y separar la capa de datos de la capa visual del template.

No construyas todavía:
- CRM
- portal de clientes
- firma electrónica
- WhatsApp API
- editor visual de templates
- múltiples agentes
- DEPASIA OS
- microservicios
- funcionalidades no solicitadas

Usa:
- Next.js
- TypeScript
- Tailwind
- shadcn/ui

Trabaja en pasos pequeños y verificables.

Si encontrás una decisión de producto que no está definida, NO la inventes. Marcala como pendiente y explicá qué necesitamos decidir.

Al finalizar esta primera etapa quiero tener una base limpia y preparada para incorporar el primer template de Presupuesto.
